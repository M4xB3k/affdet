Kitchen Object Sizes

Real-world height, longest dimension and mass for the Objaverse candidates behind the five UTAMP-2 objects (plus plates and bowls). The numbers are GPT-4o estimates from ObjaTHOR 2024_08_16. An object is counted when ObjaTHOR's category name matches the role and its quality score is 7 or more. Objects whose category is a different thing are then set aside as wrong objects.

Each role has a plausible range. Values inside it are normal. Values outside it are sorted into three kinds of outlier. Where GPT-4o reported a max dimension below the height (it gave the width instead), the height is used as the longest side.

far off more than one annotation step outside the range borderline within one step (5 cm or 0.5 kg) wrong object category is something else

Overview

All columns up to Far off come from the automatic name filter. Curated is the hand-picked set, picked by eye from a wider search (salt shakers only so far), so it is a separate count, not a subset of Real.
